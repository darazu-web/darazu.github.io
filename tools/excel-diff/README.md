# 一覧差分チェッカー（list-diff-checker.xlsx）

2 つの一覧（Before / After、旧 / 新、システム A / システム B など）を突き合わせて、
**追加・削除・変更された行**と、**変更された列とその値**を自動で抽出する Excel テンプレートです。

- マクロなし（`.xlsx`）。セキュリティ警告が出ません。
- データを貼り付けるだけ。数式なので設定を変えると即座に再計算されます。
- 対象: Excel 2019 / Microsoft 365 以降（`TEXTJOIN` を使用）。

## 使い方

1. `リストA` に比較元、`リストB` に比較先を貼り付ける（1 行目＝見出し、2 行目以降＝データ）
2. `設定` シートでキー列（行を突き合わせる目印の列）を選ぶ
3. `差分結果` シートを「状態」列でフィルターする。全体の件数と警告は `サマリー` シート

## 判定

| 状態 | 意味 |
| --- | --- |
| 一致 | キーが一致し、値にも差異なし |
| 変更 | キーは一致するが、どこかの列の値が違う（`差異内容` 列に `【列名】旧 → 新`） |
| Aのみ | リストA にしかない＝リストB で削除された行 |
| Bのみ | リストB にしかない＝リストB で追加された行 |

## 特徴

- **複合キー**: キー列を最大 3 列まで組み合わせ
- **表記ゆれの吸収**: 全角/半角・大文字小文字・前後の空白・記号を無視して照合（設定シートで切替）
- **列順に依存しない**: 見出しの名前で対応付けるため、2 つの一覧で列の並びが違っても比較できる
- **重複キーに対応**: 同じキーが複数あっても出現順に 1 対 1 で対応付ける（A に 3 件・B に 2 件なら 1 件が「Aのみ」）
- **警告**: キー重複・キーが空白・列の欠落・行数の上限超過を検知
- **列ごとの差異件数**: どの列がよく変わったかを `サマリー` に集計

## 制限

- 既定で 1 つの一覧につき **3,000 行 × 20 列**
- キーが 255 文字を超えると重複判定が正しく行えません
- `差分結果` は数式のため、並べ替えは行わず値貼り付け後に実行してください
- 数万行を超える場合は Excel の Power Query（データ → データの取得 → クエリのマージ）が高速です

## 再生成

`build_workbook.py` がこのファイルを生成します（`openpyxl` が必要）。

```bash
pip install openpyxl
python3 build_workbook.py list-diff-checker.xlsx

# 行数の上限を変えて生成する（例: 20,000 行）
DIFF_NROW=20000 python3 build_workbook.py list-diff-checker-20k.xlsx
```

行数を増やすとファイルサイズと再計算時間も増えます（3,000 行で約 2.5 MB / 数式 30 万本）。
