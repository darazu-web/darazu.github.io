# 検査情報アプリ（スタンドアロン版）

製品の検査時に「検査項目・検査方法・使用設備・特記事項・その他」を確認するアプリです。
GitHub や Microsoft 365 などのサービスを使わず、**社内の PC やサーバー 1 台**で動きます。

- 必要なもの：**Python 3.8 以上**だけです（追加のインストールは不要）
- 対応 OS：Windows / Mac / Linux（Docker でも動きます）
- 使う端末：同じネットワークのパソコン・タブレット・スマホのブラウザ
- データは、このフォルダーの `data/` に保存されます。インターネットには出ません。

```
 作業者の端末（ブラウザ） ──┐
                            ├──▶ サーバー PC（server.py） ── data/data.json
 管理者の端末（ブラウザ） ──┘        閲覧：ログイン不要
                                     変更：管理者ログインが必要
```

## 管理者だけが変更できる仕組み

- 閲覧（`http://<サーバー>:8080/`）はログイン不要です。
- 変更（`http://<サーバー>:8080/admin.html`）は、サーバーに登録した管理者がログインした場合だけ保存できます。保存はサーバー側で確認しているので、画面を細工しても変更できません。
- 管理者の登録・削除は、サーバー PC でコマンドを実行して行います（下記）。
- パスワードはハッシュ化（PBKDF2）して保存します。ログインに 5 回失敗すると、60 秒間ログインを受け付けません。
- 保存するたびに**変更履歴**が残り（最大 200 件）、管理画面の「変更履歴」から過去の版に戻せます。
  ログイン・保存の記録は `data/audit.log` に残ります。

## はじめ方

### 1. Python を用意する

- **Windows**：[python.org](https://www.python.org/downloads/) からインストールします。インストール時に「Add python.exe to PATH」にチェックを入れてください。
- **Mac / Linux**：多くの場合インストール済みです。`python3 --version` で確認できます。

### 2. このフォルダーをサーバー PC にコピーする

`standalone` フォルダーをまるごと、サーバーにする PC の好きな場所にコピーします。

### 3. 管理者を登録する

フォルダー内でコマンドプロンプト（Mac / Linux はターミナル）を開いて実行します。

```
python server.py adduser 管理者名
```

パスワード（8 文字以上）を 2 回入力します。Mac / Linux では `python` を `python3` に読み替えてください。

### 4. 起動する

- **Windows**：`start.bat` をダブルクリック
- **Mac / Linux**：`./start.sh`

起動すると次のように表示されます。

```
検査情報アプリを起動しました: http://localhost:8080/
```

ほかの端末からは `http://<サーバー PC の IP アドレス>:8080/` で開きます。
IP アドレスは、Windows では `ipconfig`、Mac / Linux では `ip addr` や `ifconfig` で確認できます。

> **Windows のファイアウォール**：初回起動時に「アクセスを許可する」画面が出たら、**プライベート ネットワーク**を許可してください。

### 5. 内容を登録する

1. `http://<サーバー>:8080/admin.html` を開き、管理者でログインします。
2. 記入例の製品が入っているので、実際の製品・検査項目に書き換えるか、「＋ 製品追加」で追加します。
3. 「保存（公開）」を押し、変更内容のメモを入力します。閲覧画面を開き直すと反映されます。

Web 版の `inspection/data.json` や Microsoft 365 版のサンプルと同じ形式なので、「JSON読込」でそのまま取り込めます。

## 画面でできること

**閲覧画面**（全員）

- 製品を選び、検査項目の一覧から項目を選ぶ
- 項目ごとに表示：**特記事項**（黄色の警告枠）、**検査方法**（番号付きの手順）、判定基準、
  **使用設備**（テスター品番・テスター名・周辺設備・ハーネス・ソフトウェア）、その他
- 「次の項目 →」ボタン（またはキーボードの ← →）で検査の順番どおりに進む
- 検索（項目名・品番・設備名・ハーネス品番など）
- **設備まとめ**：その製品の検査に必要な設備と、使う検査項目 No. の一覧（検査前の準備用）
- 印刷、スマホ・タブレット表示
- 項目ごとに URL があるので、QR コードを作って設備に貼っておけます

**管理画面**（管理者のみ）

- 製品・検査項目の追加・編集・複製・削除、並び替え、No. の振り直し
- 周辺設備・ハーネス・ソフトウェアの行の追加・削除
- 変更履歴の確認と、過去の版への復元
- JSON 出力（バックアップ）・JSON 読込
- ほかの管理者が先に保存していた場合は、上書きせずにお知らせします

## 管理者の管理

```
python server.py adduser 名前     # 追加（既にいればパスワード変更）
python server.py passwd 名前      # パスワード変更
python server.py deluser 名前     # 削除（ログイン中でも、すぐに編集できなくなります）
python server.py users            # 一覧
```

## 運用

| 項目 | 方法 |
| --- | --- |
| ポートを変える | `python server.py --port 8000` |
| データの場所を変える | `python server.py --data-dir D:\inspection-data` |
| バックアップ | `data/` フォルダーをコピーします（`data.json` が本体、`history/` が履歴、`users.json` が管理者） |
| PC 起動時に自動で起動（Windows） | タスク スケジューラで「コンピューターの起動時」に `start.bat` を実行するタスクを作成します |
| PC 起動時に自動で起動（Linux） | systemd のサービスとして `python3 /path/to/server.py` を登録します |
| Docker | `docker build -t inspection .` → `docker run -d -p 8080:8080 -v inspection-data:/app/data inspection`、管理者の追加は `docker exec -it <コンテナ> python server.py adduser 名前` |
| HTTPS で使う | nginx などのリバースプロキシで HTTPS にし、`--secure-cookie` を付けて起動します |

> **注意**：このアプリは社内ネットワークでの利用を想定しています。インターネットに直接公開しないでください。
> 社内でも通信を暗号化したい場合は、上の「HTTPS で使う」の構成にしてください。

## ファイル

```
standalone/
├── server.py          サーバー本体（Python 標準ライブラリのみ）
├── start.bat          起動（Windows）
├── start.sh           起動（Mac / Linux）
├── Dockerfile         Docker で動かす場合
├── sample-data.json   初回起動時のデータ（記入例）
├── static/            画面（閲覧画面は Web 版と共通、admin.* はこの版用）
├── tests/             サーバーのテスト（python -m unittest discover -s tests）
└── data/              ※起動すると作成。実データ・履歴・管理者（Git には含めません）
```
