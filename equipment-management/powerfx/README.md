# 使用者アプリ（キャンバスアプリ）の数式

フェーズ3の各画面に貼り付ける Power Fx をまとめています。
ファイル1つが画面1つに対応し、`▼ コントロール名.プロパティ` の下の式をそのまま貼り付けます。

## 貼り付ける前に

### 1. データソースを追加する
Dataverse コネクタで次の8テーブルを追加します。数式内では**表示名**で参照しています。

`設備` / `稼働ログ` / `貸出` / `使用者` / `設備種別` / `場所` / `部署` / `貸出先`

### 2. 「名前の表示」をオンにしておく
設定 > 全般 > 「データソースの表示名を使用する」がオンであることを確認します。
オフにしている場合は、数式中の表示名を論理名（`eqm_status` など）に読み替えてください。

### 3. 選択肢の書き方
Dataverse の選択肢は `'列の表示名 (テーブルの表示名)'.選択肢ラベル` で参照します。

| 使う場面 | 書き方 |
|---|---|
| 設備が空き | `'ステータス (設備)'.空き` |
| 稼働ログが稼働中 | `'状態 (稼働ログ)'.稼働中` |
| 貸出が貸出中 | `'状態 (貸出)'.貸出中` |
| 貸出区分が社外 | `'貸出区分 (貸出)'.社外` |
| ラベルが未貼付 | `'ラベル貼付状況 (設備)'.未貼付` |

`状態` は稼働ログと貸出の両方にあります。括弧の中のテーブル名で区別されるので、**必ずテーブル名まで書いてください**。

## 委任（デリゲーション）について

設備が2000件を超えても正しく動くよう、次の書き方を守っています。

- 参照列の比較は**レコードそのもの**と比べる → `Filter('設備', 場所 = galLocations.Selected)`
  （`場所.場所コード = "F1"` のように参照の先をたどると委任されません）
- 文字列は `=` と `StartsWith` だけを使う（`in` や `Search` は委任されません）
- 並べ替えは `Sort` に単一列を渡す

数式バーに青い下線の警告（委任の警告）が出たら、そこは2000件までしか見ていません。放置しないでください。

## 実装の順番

`3-1 → 3-2 → 3-3 → 3-4 → 3-5 → 3-6` までで**パイロットを開始できます**。
貸出（3-7, 3-8）とメンテ（3-9）は、使用開始・終了が定着してからで構いません。
