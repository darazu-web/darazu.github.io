# トラブルシュート

## スクリプトが動かない

### `Connect-Dataverse` でサインインできない

| 症状 | 原因 | 対応 |
|---|---|---|
| コードを入れても進まない | 別のアカウントでブラウザにサインイン済み | ブラウザのプライベートウィンドウで開く |
| `AADSTS50076`（MFA が必要） | 条件付きアクセス | そのままブラウザ側で MFA を完了させる |
| `AADSTS700016`（アプリが見つからない） | テナントでパブリッククライアントがブロックされている | アプリ登録を作り `-ClientId` `-ClientSecret` を使う |
| タイムアウトする | 15分以内にサインインが完了しなかった | もう一度実行する |

### 日本語が `????` や文字化けになる

| 場面 | 対応 |
|---|---|
| テーブルの表示名が化ける | 環境の言語に日本語が追加されているか確認（設定 > 言語） |
| CSV 投入後に化ける | CSV を「UTF-8 (BOM 付き)」で保存し直す。Shift_JIS なら `-Encoding Default` |
| コンソール出力が化ける | `chcp 65001` を実行してから PowerShell を起動する |

スクリプト側は送受信とも UTF-8 を明示しているので、化ける場合はファイルか環境の設定です。

### `Deploy-Schema.ps1` が途中で止まった

**そのまま同じコマンドをもう一度実行してください。** 作成済みのものは飛ばして続きから進みます。

| エラー | 原因 | 対応 |
|---|---|---|
| `接頭辞は後から変更できません` | 既存の公開元と接頭辞が違う | `schema/dataverse-schema.json` の接頭辞を既存に合わせる |
| `未対応の列タイプです` | JSON に想定外の `type` を書いた | `string/memo/int/bool/date/datetime/choice` のいずれかにする |
| 代替キーが `Active` にならない | インデックス作成が混んでいる | 10分待って再実行。それでも駄目なら対象テーブルの重複データを疑う |
| `SQL Server error` 系 | 同名の列が論理削除で残っている | 環境を作り直すのが最も早い（開発環境なら） |

### `Deploy-Security.ps1` で「特権が見つかりません」

`Deploy-Schema.ps1` の公開が終わっていません。数分待ってから再実行してください。

テーブルを作ると Dataverse が自動で `prvCreateeqm_equipment` のような特権を生成しますが、
公開（PublishAllXml）が完了するまで検索に出てこないことがあります。

### `Import-MasterData.ps1` で行がエラーになる

エラーメッセージに行番号が出ます。

| メッセージ | 原因 |
|---|---|
| `選択肢にありません` | ラベルの打ち間違い。全角/半角、スペースの有無を確認 |
| `A record with the specified key values does not exist` | 参照先の値が存在しない（例：場所コード `F9`） |
| `Cannot insert duplicate key` | 代替キー以外の一意制約に当たっている |
| 日付が変換できない | `2024/4/1` や `2024-04-01` の形式にする |

`-WhatIfOnly` を付けると、書き込まずに各行が何を送ろうとしているか確認できます。

## アプリが動かない

### 全員がブロック画面に飛ぶ

1. 使用者マスタに自分の行があるか
2. `UPN` が**小文字**で入っているか
3. `有効` が「有効」になっているか
4. `UPN` が**メールアドレス（Mail）ではなく UPN** か

`User().Email` はサインイン中のアカウントの UPN を返します。
エイリアスのメールアドレスとは別物です。

### 一覧に設備が出てこない / 途中までしか出ない

委任の上限（2000件）に達しています。数式バーの青い下線を探してください。

よくある原因：

```
// 委任されない（参照の先をたどっている）
Filter('設備', 場所.場所コード = "F1")

// 委任される（レコードそのものと比較）
Filter('設備', 場所 = varLocation)
```

```
// 委任されない
Search('設備', txtSearch.Text, "eqm_name")

// 委任される
Filter('設備', StartsWith(設備名, txtSearch.Text))
```

### 「使用を終了する」が出ない

仕様です。自分が使用開始した設備か、管理者アカウントでのみ出ます。

他人の使用を勝手に終了できると、稼働ログが誰のものか分からなくなるためです。
管理者が終了させる場合は、管理者アプリの「強制終了」コマンドを使ってください。

### 保存できない / 押しても何も起きない

1. 画面上端に赤帯（オフライン警告）が出ていないか
2. 出ていれば電波の届く場所へ移動する
3. 出ていないのに保存できない場合は、セキュリティロールを確認

**オフラインで押した操作は保存されません。** 一時保存もされません。

### 選択肢が `'ステータス (設備)'.空き` で解決しない

| 原因 | 対応 |
|---|---|
| 表示名を変えた | 数式側も変える。`Test-Solution.ps1` で検出できる |
| 「表示名を使用する」がオフ | 設定 > 全般 で確認。または論理名で書く |
| データソースが追加されていない | 設備テーブルをデータソースに追加 |

## データがおかしい

### 設備が「使用中」のまま誰も使っていない

整合性チェック（5-3）が翌朝自動で直します。急ぐ場合は管理者アプリの
「状態の手動修正」コマンド（4-9）で「空き」に戻してください。

繰り返し起きる場合は、その場所の電波状況を疑ってください。
使用開始の2回の書き込み（ログ作成 → 設備更新）の間で切れています。

### 稼働時間が明らかにおかしい

| 症状 | 原因 |
|---|---|
| 1分未満のログが大量 | 誤操作。開始直後に終了を押している。ボタンの配置を見直す |
| 24時間超のログ | 終了忘れ。5-5 の通知で拾う |
| 負の値 | 終了日時を手で直したときに開始日時より前にした。稼働時間も手で直す |
| 9時間ずれている | フローで日時列を日本時間に変換してから `utcNow()` と比べている |

最後のものは `flows/README.md` の「タイムゾーン」を読んでください。

### 短縮番号が重複した

代替キーがあるので Dataverse 側では発生しません。CSV 段階で重複している場合は
`New-ShortNumber.ps1 -Verify` が検出します。

すでにラベルを貼ってしまった後で気づいた場合：

1. 片方の設備の番号を、その場所の空き番号に変更する
2. その1台だけラベルを貼り替える
3. **番号体系全体を作り直さない**（全台貼り替えになる）

## 検査ツール

```powershell
# スキーマ・数式・CSV・セキュリティ定義の食い違いを検出（通信しない）
.\Test-Solution.ps1

# 短縮番号の重複・帯外・桁落ちを検出（通信しない）
.\New-ShortNumber.ps1 -Verify

# 何が作られるかだけ確認（書き込まない）
.\Deploy-Schema.ps1     -EnvironmentUrl '<URL>' -WhatIfOnly
.\Import-MasterData.ps1 -EnvironmentUrl '<URL>' -All -WhatIfOnly
```

**列の表示名を1つ変えると、数式・CSV の見出し・セキュリティ定義の3か所がずれます。**
スキーマを触ったら必ず `Test-Solution.ps1` を流してください。
