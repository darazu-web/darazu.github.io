## 6-1 対象範囲

| 項目 | 目安 | 理由 |
|---|---|---|
| エリア | 1つ | 場所をまたぐと「どこにあるか分からない」問題が混ざって切り分けできない |
| 設備 | 20台程度 | ラベル貼付が1日で終わる量 |
| 使用者 | 10〜20人 | 全員に直接声をかけられる人数 |

**使用頻度の高い設備を選んでください。** 月1回しか使わない設備を20台選ぶと、
4週間で数件しかログが溜まらず、何も分かりません。

「毎日誰かが使う設備」が半分以上を占めるように選ぶのが要点です。

## 6-2 ラベル貼付

`print/label-sheet.html` をブラウザで開き、CSV を読み込んで印刷します。

- 用紙：A4 / ラベルシール（24面 70×33.9mm）または普通紙＋透明テープ
- 貼る位置：**操作する人の目線で、設備の正面**。側面や裏面に貼ると読まれません
- 屋外・油がかかる場所：ラミネート、または耐水ラベル

**この工程は人手と時間が読みにくい**ので、20台で実測してください。
1台あたり何分かかったかを記録しておくと、フェーズ7-1 の見積もりが立ちます。

貼ったら管理者アプリの「ラベル未貼付一覧」で一括編集し、`貼付済` に更新します。

## 6-3 操作説明

**動画やマニュアルにしないでください。読まれません。**

`print/quick-guide-a4.html` を印刷して、**設備のそばに貼る**のが最も効きます。

| やること | やらないこと |
|---|---|
| A4 1枚、図で2ステップ | 動画 |
| 「番号を入れる → 緑のボタンを押す」 | 全機能を網羅したマニュアル |
| 設備のそばに貼る | 共有フォルダーに置く |
| 画面写真を実物に差し替える | 文字だけの説明 |

雛形には画面写真の差し込み枠があります。**実際のアプリのスクリーンショットに必ず差し替えてください。**
現場は画面の色と形で操作を覚えます。

配布ではなく**掲示**してください。配った紙は捨てられます。

## 6-4 4週間の試行運用

### 週次でやること

| 週 | 見ること |
|---|---|
| 1週目 | 毎日ログを見る。使えていない人に直接声をかける |
| 2週目 | 整合性チェック（5-3）の件数。ここが多いなら通信か操作に問題がある |
| 3週目 | 長時間稼働通知（5-5）の件数。終了忘れの実態 |
| 4週目 | 稼働ログの件数が安定しているか。減っていたら使われなくなっている |

**使用開始だけされて終了されない**のが最も多い失敗パターンです。
1週目で兆候が出るので、見つけたらすぐ 6-3 の紙と画面を見直してください。

### 記録しておくこと

```
日付 / 稼働ログ件数 / 終了忘れ件数 / 整合性チェックの検出件数 / 問い合わせ内容
```

これが 6-5 と 7-5 の判断材料になります。

## 6-5 ログの妥当性確認・閾値調整

### 確認すること

| 観点 | 見方 | おかしいときに疑うこと |
|---|---|---|
| 稼働時間の分布 | 稼働ログの稼働時間をヒストグラムに | 極端に短い（1分未満）＝誤操作、極端に長い（24時間超）＝終了忘れ |
| 1日あたりの件数 | 日別のログ件数 | 台数×使用回数と合っているか |
| 使っていない人 | 使用者別のログ件数が0 | アプリに入れていない可能性（UPN 未設定を確認） |
| 使われていない設備 | 設備別のログ件数が0 | ラベルが読めない位置に貼られている可能性 |

### 調整する閾値

| 閾値 | 既定 | 見直しの目安 |
|---|---|---|
| 長時間稼働通知（5-5） | 24時間 | 2日にまたがる作業が普通なら伸ばす |
| 返却期限の事前通知（5-1） | 1日前 | 社外貸出が多いなら3日前に |
| メンテ期限通知（5-2） | 7日前 | 部品調達が要るなら14日前に |

**通知を増やして問題を解決しようとしないでください。** 読まれない通知が増えるだけです。

## 6-6 現場ヒアリング

4週目の終わりに、実際に使った人に**直接**聞きます。アンケートではなく口頭で。

聞くこと：

1. 「使い始めるとき、どこで迷いましたか」
2. 「終了を忘れたことはありますか。あるとき、何をしていましたか」
3. 「番号を入れるのとギャラリーから選ぶの、どちらを使っていますか」
4. 「これがあると助かる、というものはありますか」

3 の答えで、フェーズ7 でどちらの導線を主にするかが決まります。
4 は聞くだけにして、**その場では約束しないでください**。

## 完了条件

- [ ] 4週間で稼働ログが期待どおりの件数溜まった
- [ ] 終了忘れの発生率を数字で把握した
- [ ] 整合性チェックの検出件数が週あたり数件以下に収まっている
- [ ] 現場から「これなら続けられる」という感触が得られた
- [ ] 稼働可能時間の定義に使える実データが揃った（→ 7-5）

**続けられそうにない**という結論も、この段階なら安いコストで得られます。
その場合は範囲を広げず、画面と紙を作り直してもう一度4週間やってください。
