## アプリの作り方

1. make.powerapps.com > ソリューション > **設備管理** を開く
2. 新規 > アプリ > キャンバスアプリ > **タブレット** レイアウト
   - 名前：`設備管理`
   - **必ずソリューションの中で作ってください**（外で作ると本番移送できません）
3. データソースに Dataverse の8テーブルを追加
4. `powerfx/README.md` の手順に従って画面を作り、数式を貼り付ける

## 画面遷移

```
          （未登録）
App.StartScreen ──→ scrBlocked
      │
      └─（登録済）→ scrHome ──┬──→ scrKeypad ──→ scrDetail
                               ├──→ scrSearch ──→ scrDetail
                               ├──→ scrScan   ──→ scrDetail
                               └──→ scrMyHistory ──→ scrDetail
                                                       │
                                       ┌───────────────┼───────────────┐
                                       ↓               ↓               ↓
                                    scrLoan        scrReturn     scrMaintenance
```

`scrDetail` が中心です。**どの経路から来ても同じ画面に着く**ようにしてあります。

## タブレットではなく電話レイアウトにしたい場合

現場がスマートフォンで使うなら電話レイアウトのほうが向いています。
数式はそのまま使えます。変えるのは配置だけです。

ただし**テンキーのボタンサイズ（96px）は縮めないでください**。
手袋をしたまま押せる大きさが、この画面の唯一の要件です。

## 設計上の要点

### 1. Patch の前に必ず最新状態を取り直す

2人が同時に同じ設備を触ったとき、後から押した人が黙って上書きしてしまうのを防ぎます。

```
With({ 最新: LookUp('設備', 短縮番号 = varEquipment.短縮番号) },
    If(最新.ステータス <> 'ステータス (設備)'.空き,
       ... 画面を更新して知らせるだけ ...,
       ... 実際の書き込み ...))
```

現場では「押したのに反応しない」より「誰かが先に使い始めました」と出るほうが親切です。

### 2. 押せるボタンだけを出す

押せないボタンをグレーで並べると、現場は「壊れている」と判断します。
`Visible` で出し分けてください（`scr_Detail.fx` 参照）。

### 3. 結果を必ず知らせる

`Patch` のあとは必ず `Notify()` を出します。
無音で成功すると、現場は不安になって2回押します。

### 4. 委任の警告を放置しない

数式バーに青い下線が出たら、そこは2000件までしか見ていません。
設備が2000件を超えた瞬間、一覧から設備が消えます。
`powerfx/README.md` の「委任について」を読んでから数式を変えてください。

## テストの観点

パイロット開始前に、**実機（現場で使う端末）で**次を確認してください。

- [ ] 未登録のアカウントでサインインすると `scrBlocked` が出る
- [ ] テンキーで存在しない番号を入れるとエラーが出て、画面が進まない
- [ ] 使用開始 → 別端末で同じ設備を開くと「使用中」になっている
- [ ] 使用中の設備を**他人のアカウント**で開くと「使用を終了する」が出ない
- [ ] 管理者アカウントでは他人の使用中でも終了できる
- [ ] 機内モードにすると赤帯が出て、操作ボタンが押せない
- [ ] 使用開始 → 機内モード → 使用終了を押す → 保存されない旨が出る
- [ ] 廃棄した設備がホーム画面と検索結果に出てこない

最後の2つは特に忘れられがちです。倉庫や屋外は電波が弱いので、必ず試してください。
