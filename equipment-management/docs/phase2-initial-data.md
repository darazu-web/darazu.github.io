## CSV の扱い方

`data/` に雛形が入っています。**見出し行は Dataverse の表示名と完全に一致させてください**
（`Test-Solution.ps1` が食い違いを検出します）。

| ファイル | テーブル | 代替キー列 |
|---|---|---|
| `eqm_equipmenttypes.csv` | 設備種別 | 種別コード |
| `eqm_locations.csv` | 場所 | 場所コード |
| `eqm_departments.csv` | 部署 | 部署コード |
| `eqm_borrowers.csv` | 貸出先 | 貸出先コード |
| `eqm_users.csv` | 使用者 | 社員番号 |
| `eqm_equipments.csv` | 設備 | 設備コード |

### 参照列の書き方

参照列には**参照先の代替キーの値**を書きます。GUID は不要です。

| 設備 CSV の列 | 書く値 | 例 |
|---|---|---|
| 種別 | 設備種別の**種別コード** | `PC` |
| 場所 | 場所の**場所コード** | `F1` |
| 管理部署 | 部署の**部署コード** | `MFG1` |

### 選択肢の書き方

選択肢のラベルをそのまま書きます（`空き`、`未貼付` など）。数値でも受け付けます。

### Excel で編集するときの注意

- **必ず「UTF-8 (BOM 付き)」で保存**してください。雛形はその形式です。
  Excel の「CSV UTF-8 (コンマ区切り)」で保存すれば大丈夫です。
- **短縮番号の先頭のゼロが消えます。** `0101` が `101` になります。
  短縮番号の列は**書式設定を「文字列」にしてから**入力してください。
  `New-ShortNumber.ps1` は桁落ちを検出して警告します。
- Shift_JIS で保存してしまった場合は `-Encoding Default` を付けて取り込めます。

```powershell
.\Import-MasterData.ps1 -EnvironmentUrl '...' -All -Encoding Default
```

## 2-1 〜 2-3 の実行


投入順は `設備種別 → 場所 → 部署 → 貸出先 → 使用者 → 設備` に固定されています。
参照先が先に入っていないと結べないためです。

**代替キーによる upsert なので、何度流しても重複しません。**
台帳を直したら CSV を直して流し直すだけです。差分を意識する必要はありません。

## 2-2 Entra ID との突合

使用者マスタの `UPN` 列が突合キーです。アプリはここで人を特定します。

```
App.StartScreen:  LookUp('使用者', Lower(UPN) = Lower(User().Email) And 有効 = true)
```

### UPN の取り方

管理者権限のある PowerShell で Microsoft Graph から取得するのが確実です。

```powershell
# Microsoft.Graph モジュールが必要
Connect-MgGraph -Scopes 'User.Read.All'
Get-MgUser -All -Property Id,UserPrincipalName,DisplayName,EmployeeId,Mail |
    Select-Object @{n='社員番号';e={$_.EmployeeId}},
                  @{n='氏名';e={$_.DisplayName}},
                  @{n='UPN';e={$_.UserPrincipalName.ToLower()}},
                  @{n='EntraオブジェクトID';e={$_.Id}} |
    Export-Csv .\entra-users.csv -NoTypeInformation -Encoding utf8BOM
```

出力を `eqm_users.csv` に貼り付け、`部署`・`既定の場所`・`役割` を埋めてから投入します。

### よくある落とし穴

| 症状 | 原因 |
|---|---|
| 全員がブロック画面に飛ぶ | UPN が大文字混じり。`Lower()` で比較しているので投入時も小文字に揃える |
| 一部の人だけ弾かれる | メールアドレス（`Mail`）と UPN が違う人。**必ず UPN のほう**を入れる |
| 登録したのに弾かれる | `有効` が `いいえ` になっている |

`User().Email` はサインイン中のアカウントの UPN を返します。エイリアスではありません。

## 2-4 短縮番号の採番

**Excel 側で採番してから取り込むのが確実です。** 投入後に採番し直すと、
ラベルを貼り替える羽目になります。

### 番号帯の設計

場所ごとに番号帯を分けると、現場が番号から場所を推測できます。

| 場所 | 番号帯 | 容量 |
|---|---|---|
| 本館1階 | 0100〜0199 | 100 |
| 本館2階 | 0200〜0299 | 100 |
| 本館3階 | 0300〜0399 | 100 |
| 第1倉庫 | 0400〜0499 | 100 |
| 屋外ヤード | 0500〜0599 | 100 |

`eqm_locations.csv` の `番号帯開始` / `番号帯終了` で設定します。
**将来の増設を見込んで、現在の台数の2倍以上の幅を取ってください。**
帯が満杯になると番号体系を作り直すことになり、ラベルを全部貼り替えることになります。

### 実行

```powershell
# 空欄の短縮番号を場所ごとの帯から採番する
.\New-ShortNumber.ps1

# 検査だけしたいとき（重複・帯外・桁落ちを見る）
.\New-ShortNumber.ps1 -Verify

# すでに本番にある番号を避けて採番したいとき
.\New-ShortNumber.ps1 -ExistingNumbersCsv .\live-numbers.csv
```

出力は `eqm_equipments_numbered.csv` です。中身を確認してから元ファイルを置き換えてください。

このスクリプトは Dataverse に接続しません。手元の CSV だけで完結するので、
ネットワークやライセンスを気にせず何度でも試せます。

検出する問題：

- 同じ番号が2行以上にある
- 場所の番号帯の外にある番号
- 先頭のゼロが落ちている（`201` のように桁が足りない）
- 場所マスタにない場所コードが書かれている
- 数字以外が混ざっている

**1件でも問題があると採番を実行しません。** 中途半端に採番して傷口が広がるのを防ぐためです。

### QR コード値

採番時、`QRコード値` が空の行には短縮番号と同じ値が自動で入ります。
これにより、フェーズ3-11 のスキャン処理をテンキー入力とまったく同じ経路で扱えます。

## 2-5 初期ステータス

CSV の `ステータス` 列に `空き` を入れておけば、投入時に設定されます。
雛形はそうなっています。

投入後の確認（管理者アプリの高度な検索、または）：

```
設備で ステータス が 空き 以外 の行を数える → 0 件であること
```

廃棄済みの設備を最初から入れる場合だけは `廃棄` にしてください。
`廃棄` の設備はアプリの一覧にも検索結果にも出ません。
