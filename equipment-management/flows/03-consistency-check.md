# 5-3 整合性チェック（日次）

`設備-整合性チェック`

設備テーブルの「現在の状態」と、稼働ログ・貸出の実体がずれていないかを毎朝調べます。

## なぜ必要か

設備のステータスは、アプリが2回の書き込み（稼働ログを作る → 設備を更新する）で維持しています。
その間で通信が切れると、**片方だけ書かれた状態**が残ります。

- 稼働ログは「稼働中」なのに、設備は「空き」→ 誰も使っていないのに終了できないログが残る
- 設備は「使用中」なのに、稼働中のログがない → 誰も使っていないのに誰も使えない設備ができる

こうなると現場は「アプリが壊れている」と判断して使うのをやめます。
**毎日見つけて直せば、現場はその存在に気づきません。**

## トリガー

**繰り返し** / 1日 / (UTC+09:00) 大阪、札幌、東京 / 7:50
（5-1, 5-2 より先に流して、直した結果が他の通知に反映されるようにします）

## チェック1：設備は「使用中」だが稼働中ログがない

**行を一覧する** / 設備 / フィルター行:

```
statecode eq 0 and eqm_status eq 2 and eqm_CurrentLogId eq null
```

さらに `eqm_CurrentLogId` が入っていてもログ側が完了している場合があるので、
拾った各行について **行を一覧する**（稼働ログ）で確認します。

| 項目 | 値 |
|---|---|
| テーブル名 | 稼働ログ (`eqm_operationlogs`) |
| フィルター行 | `statecode eq 0 and eqm_state eq 1 and _eqm_equipmentid_value eq @{items('使用中の設備')?['eqm_equipmentid']}` |
| 行数 | 1 |

**条件**: `length(body('稼働中ログを確認')?['value'])` が **0 に等しい**

はいの場合 → 設備を「空き」に戻し、記録を残します。

**行を更新する** / 設備 / 行 ID `items('使用中の設備')?['eqm_equipmentid']`

| 列 | 値 |
|---|---|
| ステータス | `1`（空き） |
| 現在の使用者 | （空にする） |
| 現在の稼働ログ | （空にする） |
| 現在の使用開始日時 | （空にする） |
| 備考 | `@{items('使用中の設備')?['eqm_note']}@{formatDateTime(utcNow(),'yyyy/MM/dd')} 整合性チェックにより空きへ戻しました（稼働中ログなし）` |

> 参照列を空にするには「行を更新する」の詳細オプションで該当列に何も入れず、
> 「高度なオプションを表示する」→ 該当の参照列に `null` を指定します。
> うまくいかない場合は、**行の関連付けを解除する** アクションを使ってください。

## チェック2：稼働ログは「稼働中」だが設備が使用中でない

**行を一覧する** / 稼働ログ / フィルター行:

```
statecode eq 0 and eqm_state eq 1
```

展開クエリ: `eqm_EquipmentId($select=eqm_shortnumber,eqm_name,eqm_status)`

**条件**: `items('稼働中ログ')?['eqm_EquipmentId']?['eqm_status']` が **2 に等しくない**

はいの場合 → **自動では閉じません。管理者に報告するだけにします。**

自動で閉じると、実際に使用中だった記録の終了時刻が勝手に決まってしまいます。
稼働時間の集計が狂うくらいなら、人が見て判断したほうが安全です。

## チェック3：設備は「貸出中」だが未返却の貸出がない

**行を一覧する** / 設備 / フィルター行: `statecode eq 0 and eqm_status eq 3`

各行について **行を一覧する** / 貸出 / フィルター行:

```
statecode eq 0 and eqm_state ne 2 and _eqm_equipmentid_value eq @{items('貸出中の設備')?['eqm_equipmentid']}
```

0件なら管理者に報告します（こちらも自動では戻しません。持ち出された物が手元にない可能性があるため）。

## チェック4：短縮番号が空の設備

**行を一覧する** / 設備 / フィルター行: `statecode eq 0 and eqm_shortnumber eq null and eqm_status ne 6`

代替キーがあるので重複は発生しませんが、**空のまま投入された設備**は起こり得ます。
短縮番号が空の設備はテンキーから呼び出せないので、現場では「アプリに載っていない設備」になります。

## 報告メール

4つのチェック結果を1通にまとめます。

| 項目 | 値 |
|---|---|
| 宛先 | 管理者グループ |
| 件名 | `【設備】整合性チェック @{convertTimeZone(utcNow(),'UTC','Tokyo Standard Time','yyyy/MM/dd')}` |
| 送信条件 | 4つの合計件数が 0 **より大きい** とき |

自動で直した分（チェック1）と、人の確認が要る分（チェック2〜4）を**本文で分けて**書いてください。
混ざっていると、読む人が毎回全部を確認し直すことになります。
