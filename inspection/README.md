# 検査情報アプリ

製品の検査時に「検査項目・検査方法・使用設備・特記事項」をすぐ確認するためのアプリです。
誰でも閲覧でき、内容の変更は管理者だけが行えます。

| 画面 | URL | 対象 |
| --- | --- | --- |
| 閲覧画面 | `https://darazu-web.github.io/inspection/` | 検査作業者 |
| 管理画面 | `https://darazu-web.github.io/inspection/admin.html` | 管理者のみ |

## 閲覧画面でできること

- 製品を選び、検査項目の一覧から項目を選ぶ
- 項目ごとに表示される内容
  - **特記事項**：黄色の警告枠で先頭に表示
  - **検査方法**：番号付きの手順、判定基準
  - **使用設備**：テスター品番、テスター名、周辺設備、ハーネス、ソフトウェア（バージョン）
  - **その他**
- 「前へ／次へ」ボタン（またはキーボードの ← →）で、検査順に項目を移動
- 検索：項目名・品番・設備名・ハーネス品番などで絞り込み
- **設備まとめ**：その製品の検査に必要な設備をまとめて表示（検査前の準備用）
- 印刷、スマホ／タブレット表示に対応
- URLに製品・項目が含まれるため、ブックマークやQRコードで特定の項目を直接開けます

## 管理者だけが変更できる仕組み

データは `inspection/data.json` に保存されています。管理画面での「保存（公開）」は
GitHub API でこのファイルを更新するため、**このリポジトリへの書き込み権限を持つ GitHub アカウント**
のトークンがないと保存できません。権限のないアカウントではログイン時に拒否されます。
変更はすべて GitHub のコミット履歴に残り、いつ・誰が・何を変えたか確認・復元できます。

### 管理者の準備（初回のみ）

1. GitHub の **Settings → Developer settings → Personal access tokens → Fine-grained tokens** で
   **Generate new token** を選ぶ
2. Repository access で `darazu-web/darazu.github.io` のみを選択
3. Permissions → Repository permissions → **Contents: Read and write** を設定して作成
4. 表示されたトークン（`github_pat_...`）を安全な場所に保管

管理者を追加・削除するときは、リポジトリの **Settings → Collaborators** で書き込み権限を付与・削除します。

### 編集手順

1. 管理画面を開き、トークンを入力してログイン
2. 製品を選び、「製品情報」または検査項目を編集
   - 検査方法の「手順」は 1 行が 1 ステップになります
   - 周辺設備・ハーネス・ソフトウェアは「＋追加」で行を増やせます
   - ▲▼で並び替え、「No.を振り直す」で番号を整えられます
3. 「保存（公開）」を押し、変更内容のメモを入力
4. 数分以内に閲覧画面へ反映されます

トークンはブラウザのタブを閉じると破棄されます。トークンなしでも「JSON出力」で
`data.json` を作成でき、GitHub 上で直接アップロードして反映することもできます。

## ファイル構成

```
inspection/
├── index.html   閲覧画面
├── admin.html   管理画面
├── data.json    検査データ（管理画面から更新）
├── app.css      共通スタイル
├── common.js    共通処理
├── viewer.js    閲覧画面の処理
└── admin.js     管理画面の処理
```
