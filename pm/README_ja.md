# プロジェクト管理ツール

自分のタスク・チームの進捗フォロー・部下の育成を、個人で管理するためのWebアプリです。
データはこの端末のブラウザ内（localStorage）だけに保存され、GitHubには送られません。

## いまの状態：① マイタスク 完成

- ✅ ①マイタスク：追加 / 未着手→作業中→完了 の移動 / 削除 / 保存
- ⬜ ②チーム進捗：案件ごとの進捗バー・担当・状況メモ
- ⬜ ③育成メモ：部下ごとの目標・1on1メモ・成長記録
- ⬜ 共通：データの書き出し（バックアップ）/ 読み込み

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造（タブ・入力欄・3つの列） |
| `style.css`  | 見た目のデザイン |
| `app.js`     | 処理（追加・移動・削除・保存） |

## 動かし方

### PCで確認する
1. このフォルダで簡易サーバーを立てる（例：`python3 -m http.server`）
2. ブラウザで `http://localhost:8000/pm/` を開く
   - ※ このアプリは `file://` で直接開いても動きます。

### 公開して使う
1. GitHub に push する
2. GitHub Pages が `main` ブランチを公開している場合、`https://darazu.github.io/pm/` で使えます

## メモ
- データは「その端末・そのブラウザ」だけに残ります。ブラウザのデータを消すと失われます。
- 機微な情報（部下の実名など）はコードに直接書かず、必ず画面の入力欄から入れてください。
