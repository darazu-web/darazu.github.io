# darazu.github.io

## 入出庫・納期管理アプリ

`inventory.html` … 入庫・出庫の進捗と、顧客からの要望納期・優先順位を一元管理する単一ページアプリです。**分納（複数回入庫・複数回出庫）に対応**しています。

公開URL（GitHub Pages を有効化し、main ブランチから配信している場合）:
https://darazu-web.github.io/darazu.github.io/inventory.html

> このリポジトリは `darazu-web/darazu.github.io` で、オーナー名とリポジトリ名が一致しないため
> ユーザーサイト（`https://darazu-web.github.io/`）ではなく**プロジェクトサイト**として配信されます。
> URL にリポジトリ名が1階層入る点に注意してください。

### 主な機能

**分納（入出庫履歴）**
- 1つの注文に対して、入庫を何回でも「日付・数量・LOT番号・備考」単位で記録できます。出庫も同様に分割出荷を記録できます。
- 明細は累計・残数つきで表示され、どこまで入って・どこまで出したかが1行で追えます（行頭の ▸ で展開）。
- 一覧の「＋入庫」「＋出庫」ボタンから、その場で1回分を追記できます。

**管理項目**
- 注文単位: 品番 / 数量（受注総数） / 要望納期 / 顧客名 / 注文・管理番号 / 入庫予定日 / 出庫予定日 / LOT番号（代表） / 備考
- 入出庫1回ごと: 日付 / 数量 / LOT番号 / 備考

**在庫進捗（自動判定）**
- 未入庫 → 一部入庫 → 入庫完了 → 一部出庫 → 出庫済
- 入庫履歴・出庫履歴の合計から状態・進捗率・入庫残を自動計算します。

**優先順位**
- 要望納期順で自動並べ替え＋各行を▲▼で手動調整。未入庫のものも含めて把握できます。

**納期アラート**
- 超過・7日以内の要望納期を色分け表示、超過（未完了）件数をサマリー表示。

**保存とCSV**
- この端末のブラウザ内（localStorage）に自動保存。
- CSV書出 … 1行＝1注文。入出庫履歴は1セルにまとめて書き出し、読み込むと分納のまま復元されます。
- 明細CSV書出 … 1行＝1回の入出庫。Excelでのピボット集計用。
- CSV読込 … 上記の書出形式に対応。旧形式（入庫済数量＋入庫実績日）のCSVも取り込めます。

### 使い方
1. `inventory.html` をブラウザで開く（GitHub Pages公開後は上記URL）
2. 「サンプル投入」で動作を確認、または「＋ 新規登録」で入力
3. 入庫・出庫があるたびに一覧の「＋入庫」「＋出庫」で追記
4. データは自動保存。定期的に「CSV書出」でバックアップを推奨

> 注: データはブラウザごとに保存されます。別の端末・複数人でリアルタイム共有したい場合はCSVでの受け渡し、または別途サーバー/クラウドDB構成が必要です。
> 旧バージョンで登録したデータは、初回起動時に自動で分納形式へ移行されます。
