# darazu.github.io

## 入出庫・納期管理アプリ

`inventory.html` … 入庫・出庫の進捗と、顧客からの要望納期・優先順位を一元管理する単一ページアプリです。

公開URL: https://darazu-web.github.io/inventory.html

### 主な機能
- **管理項目**: 品番 / 数量 / 入庫済数量 / 要望納期 / 顧客名 / 注文・管理番号 / 入庫予定日・実績日 / 出庫予定日・実績日 / LOT番号 / 備考
- **在庫進捗（4段階＋進捗率）**: 未入庫 → 一部入庫 → 入庫完了 → 出庫済（入庫済数量÷数量から自動判定・進捗率を自動計算）
- **優先順位**: 要望納期順で自動並べ替え＋各行を▲▼で手動調整。未入庫のものも含めて把握できます。
- **納期アラート**: 超過・7日以内の要望納期を色分け表示、超過（未完了）件数をサマリー表示
- **保存**: この端末のブラウザ内（localStorage）に自動保存
- **CSV**: 書き出し（ExcelでそのままBOM付きUTF-8）／読み込みに対応。バックアップや他の人との共有に利用できます。

### 使い方
1. `inventory.html` をブラウザで開く（GitHub Pages公開後は上記URL）
2. 「サンプル投入」で動作を確認、または「＋ 新規登録」で入力
3. データは自動保存。定期的に「CSV書出」でバックアップを推奨

> 注: データはブラウザごとに保存されます。別の端末・複数人でリアルタイム共有したい場合はCSVでの受け渡し、または別途サーバー/クラウドDB構成が必要です。
