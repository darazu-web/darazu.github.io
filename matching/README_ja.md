# 照合アプリ（PWA）

リスト照合・バーコード読み取り・回数カウントを、オフラインでも使えるWebアプリ（PWA）として作っていくプロジェクトです。

## いまの状態：Step 1 + 2 まで完成

- ✅ Step1：カメラを起動する
- ✅ Step2：バーコードを読み取り、値を画面に表示・履歴に記録
- ⬜ Step3：CSVリストを取り込む
- ⬜ Step4：リストと照合して ◯✕ 表示
- ⬜ Step5：一部照合（先頭◯桁など）
- ⬜ Step6：回数カウント保存・オフライン化・ホーム画面追加（PWA化）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造（見た目の骨組み） |
| `style.css`  | 見た目のデザイン |
| `app.js`     | 処理（カメラ起動・読み取り・履歴表示） |
| `lib/html5-qrcode.min.js` | バーコード読み取りライブラリ（同梱＝オフライン可） |

## 動かし方（テスト方法）

### 大事な前提
カメラは **「https:// の安全な接続」または「localhost」でしか動きません**。
PCでファイルを直接ダブルクリック（`file://`）で開くとカメラは使えません。

### 方法A：スマホで試す（本命）
1. このフォルダを GitHub Pages で公開する
2. スマホのブラウザで `https://<ユーザー名>.github.io/matching/` を開く
3. 「スキャン開始」→ カメラ許可 → バーコードを枠に合わせる

### 方法B：PCのChromeで動作だけ確認
1. このフォルダで簡易サーバーを立てる（例：`python3 -m http.server`）
2. `http://localhost:8000/matching/` を開く

## メモ
- 対応バーコード：QR / EAN-13(JAN) / EAN-8 / UPC / CODE128 / CODE39 / ITF / CODABAR
- iPhone(Safari) / Android(Chrome) どちらでも動作します
