# 動く名刺（レベル1：動画名刺）

スマホで **自己紹介動画が自動再生される名刺ページ** です。
QRコードから開くと「人が動く名刺」になります。

## 📁 このフォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 名刺ページ本体（名前・連絡先を編集する場所） |
| `style.css`  | 見た目（色・サイズ） |
| `me.mp4`     | ← **あなたが後で置く動画ファイル**（まだ無い） |

## ✅ あなたがやること（3ステップ）

### ステップ1：動画を用意して置く
1. スマホで 5〜15秒の自己紹介動画を撮る（例：手を振って「〇〇です！」）
2. ファイル名を **`me.mp4`** にする
3. この `meishi` フォルダに置く（アップロードする）

> 縦向き動画がおすすめ（枠が縦長 3:4 のため）。
> 動画が無い間は「準備中」と表示されます。

### ステップ2：名前と連絡先を書き換える
`index.html` の `▼▼ ここから ▼▼` 〜 `▲▲ ここまで ▲▲` の間を自分の情報に変更します。
- 名前・肩書き・ひとこと
- メール / Webサイト / SNS のリンク（不要な行は削除OK）

### ステップ3：公開URLを確認してQRにする
公開URLはこうなります：

```
https://darazu-web.github.io/meishi/
```

このURLを「QRコード作成」サイトに貼ればQRコードが作れます。
それを名刺に印刷すれば完成です。

## ⚠️ よくあるつまずき

- **動画が自動再生されない** → `autoplay loop muted playsinline` の4つが揃っているか確認（消すと再生されません）
- **QRが読めない** → 印刷サイズは 2cm 角以上＋周囲に白い余白を残す
- **日本語のファイル名** → 動画は必ず半角英数字（`me.mp4`）にする

## 🎨 色を変えたい

`style.css` の先頭にある `:root { ... }` の色コード（`#6c7bff` など）を変えるだけで配色が変わります。
